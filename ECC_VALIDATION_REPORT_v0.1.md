# ECC_VALIDATION_REPORT_v0.1.md

Checking each of your 8 questions against what Evidence Pilot v0.2 actually produced — not adjusting ECC to fit the results, reporting what the results say about ECC.

## 1. Minimum Evidence Requirements — reasonable, with one open question

Theory/Model/Factor at Min 3 correctly separated the objects that got real re-verification work (T01, T05, M02, FA01 all reached 3+ and passed) from those that didn't (T02, T03, T06, T09, M01, FA03 stayed at 1–2 and failed on count alone). The bar did real discriminating work — it wasn't trivially clearable. Metric/Concept at Min 2 also held up: ME01 and C01 both needed and got a second, independent source to pass. **No evidence this round that any Min count is set wrong.**

## 2. Primary Source Requirements — reasonable, one real gray area found

T05's pass depends on Cline (2015), a Peterson Institute working paper — independently authored, empirically real, but **not peer-reviewed**. It satisfied the letter of "Primary source" but not the implicit assumption that Primary means peer-reviewed-or-equivalent. **This is a genuine calibration question ECC doesn't currently answer**: does a reputable institutional working paper count as full Primary weight, or a step below a peer-reviewed journal article? I flagged EV30's Quality as "Medium" rather than "High" specifically because of this, but ECC's Primary Requirement doesn't currently distinguish peer-reviewed from non-peer-reviewed Primary sources. Recommend this be resolved explicitly before v1.0, not left implicit.

## 3. Secondary Source Requirements — reasonable

Every Secondary source that drove a pass (EV03 for T01/ME01/C01, EV05 for T02, EV14 for C08, EV31/EV32 for FA01) was genuinely independent and added real content (a critique, a corroboration, an alternative explanation) — none were rubber-stamp citations added just to hit the count.

## 4. Independence-of-authors — practically determinable, but not free

Determining independence required an actual judgment call each time (Merton vs. Black-Scholes: co-originators, working independently, counted as independent; Modigliani-Miller 1958 vs. 1963: same authors' own follow-up, correctly did *not* count as independent). This is judgment, not a mechanical author-string comparison — a future system would need either a maintained author/institution registry or continued human review at this step. **Determinable, not automatable as currently specified.**

## 5. Critical/opposing source requirement (Theory, if contested) — applicable and it worked

T01 (Maturity = "contested") needed and found a genuine contesting source (Fama-French 1992's flat-beta finding). This is the single clearest validation in this pilot: the rule correctly forced a harder search than "any 3 citations" would have, and produced a materially more honest answer (see Research Answer Comparison). **Keep as-is.**

## 6. Standard's Currency Check — not actually tested this round

Both Standards in the pilot (S01 IFRS, S03 CFA Code) passed on a single Official Standard citation, and I did not independently re-verify that the cited editions are currently effective versions (I stated "current edition" from memory/description, not from a live check against the issuing body). **This rule exists on paper but wasn't exercised with real rigor in this pilot — a real gap in this validation, not a finding that the rule is wrong.** Needs a real test before v1.0.

## 7. Pattern's Provisional waiver — not testable this round

No Pattern objects were in the 20-object pilot (deliberately excluded from selection, per Evidence Pilot v0.1's own reasoning). **Cannot validate or invalidate this rule from this pilot.** Needs its own dedicated test, not an extrapolation from the other 20.

## 8. Systematic over/under-judging by Type

- **Theory and Factor are correctly the hardest** — by design, and the pilot confirms this is deliberate difficulty, not miscalibration: every Theory/Factor that failed did so because I ran out of search bandwidth, not because a real independent source doesn't exist (Value Factor alone turned up 2 strong independent sources on the first two targeted searches).
- **Standard and Framework may be too easy to fully validate in one pilot round** — both passed without their distinguishing checks (Currency, "does it reflect accepted standard practice") being genuinely exercised. Not necessarily wrong, but unproven.
- **No type showed evidence of being systematically mis-judged** in the sense of passing objects that shouldn't have, or failing objects that clearly had adequate real evidence available. The failures are honest capacity gaps, not calibration errors.

## Summary verdict for Freeze decision (see EVIDENCE_PILOT_v0.2.md for the formal recommendation)

Three concrete calibration gaps found: (a) Primary/peer-review distinction undefined for Theory-tier sources, (b) Currency Check never actually exercised, (c) Pattern waiver never tested. None of these are "the standard is too strict, lower it" — all three are "the standard needs a small refinement or a dedicated test," which is a materially different conclusion.
